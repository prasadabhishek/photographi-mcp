# Security Policy

## Supported Versions

We only provide security updates for the current major version.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability within photographi, please do NOT file a public issue.

Instead, please send an email to **[your email if you want, or just file a private report via GitHub if enabled]**. 

Include the following information in your report:
- Type of issue (e.g., buffer overflow, SQL injection, RCE)
- Full steps to reproduce
- Proof-of-concept (if applicable)
- Impact of the vulnerability

We will attempt to acknowledge your report within 48 hours and provide a fix as soon as possible.
